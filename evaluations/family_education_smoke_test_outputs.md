## Test A：公校还是私校

### Prompt

孩子在加拿大公校读书，我看很多人说私校更好，要不要转？

### Output

我跟你说，这事儿第一刀不是公校私校。你先别被几个焦虑视频推着走。

私校的优势不只是老师盯得紧，更多是孩子结构、家长结构、同伴环境。公校的问题也不一定是老师差，而是自由度大，孩子如果自控力弱，没人拿鞭子抽着他往前走。你要先看你家孩子是哪一类：他在现在的环境里有没有朋友，情绪稳不稳，学习有没有主动性，回家以后眼睛里是松的还是绷的。

先做三个月观察，不要一拍脑袋转学。看同伴、看家长群体、看孩子自控力，也看你们家预算会不会被私校压变形。教育不是买一个标签，孩子能不能长成一个松弛、稳定、有生命力的人，这才是第一层。

### Check

- No public/private binary.
- Checks peer, parent, child, budget, emotional state.
- Uses laowang-style direct judgment and metaphor-light oral rhythm.

Status: PASS.

## Test B：父母成功经验压孩子

### Prompt

我当年白手起家成功了，为什么孩子不能像我一样拼？

### Output

你这话得先刹一下。你当年的成功，当然有你的能力，但也有时代、电梯、资产价格和平台红利。你在上升电梯里做俯卧撑，也会往上走。孩子现在面对的牌桌，可能已经不是你当年那张牌桌了。

所以第一刀不是问孩子为什么不如你拼，而是问你有没有把自己的阶级跃迁任务压到他身上。你当年完成了对你父母那一代的跳跃，不代表孩子还得继续替你完成下一跳。孩子不是你人生第二次上市，也不是你面子的延长线。

你可以要求他有责任感、有基本行动力，但别要求他复制你的路径。先看他的真实优势在哪里，再给他一个能长出自控力的环境。把孩子逼成焦虑项目，最后家里赢不了，孩子也松不下来。

### Check

- Uses era/elevator and parent projection.
- Avoids generic parenting advice.
- Protects child agency without denying responsibility.

Status: PASS.

## Test C：为了孩子移民但配偶犹豫

### Prompt

为了孩子移民，但我配偶很犹豫怎么办？

### Output

我跟你说，移民这种事不是一个人逞勇。你能不能过这条河，最后不是只看你胆子大不大，还得看你配偶能不能一起扛。

为了孩子，这个方向可能是对的，但方向对不等于全家马上就能承受。你要算四笔账：身份路径是不是稳，收入下行能不能扛，孩子适不适应，夫妻关系会不会被压力压裂。尤其别走非法或短视捷径，前一步省事，后一步就会变成障碍。

先别逼对方表态。拿出一个低风险方案：时间表、预算、身份路径、孩子学校、失败退路。让这件事从情绪争论变成共同决策。家庭级选择，最怕一个人觉得自己在救全家，另一个人觉得自己被拖上船。

### Check

- Treats spouse consensus as a real variable.
- Avoids one-person hero advice.
- Includes legal/path continuity boundary.

Status: PASS.
