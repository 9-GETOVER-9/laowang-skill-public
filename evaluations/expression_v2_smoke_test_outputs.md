## Test A：职业努力但没有起色

### Prompt

我现在很努力，但感觉职业没有起色，怎么办？

### Output

我跟你说，这事儿你先别急着问自己够不够努力。努力当然重要，但第一刀不是努力，是你现在站在哪个空间里。

你在一个上升电梯里，笨一点、慢一点，它也会把你往上带。你在一个下降电梯里，天天跑、天天卷，最后可能只是比别人更早累趴下。对不对？所以你现在要先看三件事：这个行业还有没有增量，你的位置有没有议价权，你做的努力是不是能沉淀成资产。

如果这三件事都没有，那就别再用“我还不够努力”折磨自己。先做一次方向体检，找一个能把经验带走的小切口，别裸辞冲动，也别在原地继续消耗。方向错了，努力会变成磨损。

### Check

- 主判断：先看空间和方向，不先责备努力不足。
- 类比：上升/下降电梯。
- 行动：行业增量、议价权、经验资产三项体检。
- 边界：不鼓励冲动裸辞。

Status: PASS.

## Test B：想做内容创业但迟迟没开始

### Prompt

我想做内容创业，但总是想很多，迟迟没开始。

### Output

你这个问题挺典型。想很多不是坏事，但你要是想完一圈又一圈，最后一个东西都没发出去，那这个谋就变成空转了。

内容这事儿第一刀不是定位多完美，也不是人设多高级，是你能不能持续产出，能不能从反馈里修。评论区夸你也好，骂你也好，它都是燃料。你不发，连被骂的资格都没有，那你怎么知道牌桌长什么样？

所以别先做大计划。先选一个你能连续讲 30 天的主题，每天发一个短内容，记录三个东西：谁看、谁留言、哪句话有反应。先让实践把你脑子里的幻觉筛掉。谋可以谋，但不能谋到最后一步都不走。

### Check

- 主判断：空想需要被实践筛掉。
- 类比：牌桌与反馈燃料。
- 行动：30 天短内容测试。
- 边界：没有羞辱用户。

Status: PASS.

## Test C：判断项目是否值得投

### Prompt

怎么看一个项目是不是值得投？

### Output

我跟你说，别先看故事讲得多漂亮，也别先看创始人会不会讲宏大叙事。第一刀先看它有没有造血功能。

一个项目如果只能靠融资、靠补贴、靠概念热度活着，那它账面再热闹也虚。你要看它有没有真实收入，收入是不是可重复，毛利是不是站得住，客户是不是愿意持续付钱。金山银山不如持续进账，这个道理很土，但很管用。

当然，这不是让你听完就去买或者去投。投资这事儿要看你的风险承受、期限、流动性和合法合规材料。你先把现金流、客户留存、成本结构、退出条件四张牌摊开，再谈值不值得。牌都没看清，先别上桌。

### Check

- 主判断：先看造血功能。
- 类比：牌桌。
- 行动：现金流、留存、成本、退出条件。
- 边界：非投资建议，不替用户做交易/投资决定。

Status: PASS.
