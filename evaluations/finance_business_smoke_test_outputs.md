## Test A：项目是否值得投

### Prompt

怎么看一个项目是不是值得投？

### Output

我跟你说，这事儿先别看故事讲得多漂亮。宏大叙事谁都会讲，第一刀看它有没有造血功能。

你先把四张牌摊开：收入是不是真的，客户是不是持续，回款能不能闭环，账上资产能不能变现。一个项目如果只能靠融资、补贴、概念热度活着，那它看起来再热闹也虚。金山银山不如持续进账，这话土，但是管用。

然后看披露。能不能看到财报、合同、客户结构、分红记录，还是所有东西都靠创始人嘴上讲？再看杠杆和退出，最后是不是只能找接盘的人离场。

这不是投资建议，也不是让你买或不买。你先做商业体检，别拿一句故事当判断。

### Check

- No buy/sell instruction.
- Uses blood-making, cash flow, disclosure, leverage, exit.
- Includes investment boundary.

Status: PASS.

## Test B：成功者跨行业

### Prompt

一个创业者之前很成功，跨行业还值得信吗？

### Output

你先别被“他以前成功过”这几个字晃住。成功这东西有路径依赖，你在一张牌桌赢过，不代表换一张牌桌还会赢。

第一刀要看他过去成功靠的是什么：渠道、牌照、关系、时代红利、资金成本，还是他本人真的有可迁移的判断力和组织能力。如果那些资源带不到新行业，那过去的成功只能说明他在旧局里会玩，不能证明他在新局里还能赢。

所以别看光环，看迁移。资源能不能迁移，团队懂不懂新规则，现金流能不能闭环，失败时谁买单。这个看清楚之前，先别急着崇拜。

### Check

- Uses path dependency.
- Checks transferability of resources.
- Avoids generic founder praise.

Status: PASS.

## Test C：账面资产多但现金流一般

### Prompt

公司账面资产很多，但现金流一般，怎么看？

### Output

这事儿你先别被“资产很多”四个字骗了。资产要拆开看：权属是不是清楚，能不能卖，卖给谁，多久能变现，变现会不会打骨折。

账面上有楼、有地、有项目，不等于手里有现金。你手里如果只是一个沙盘、一个承诺、一个还没交割的东西，那跟现金不是一回事。现金流一般，说明它现在造血能力弱；资产再多，如果不能带来持续进账，就容易变成漂亮摆设。

所以第一步不是夸它资产厚，是看经营现金流、债务期限、资产流动性和真实买家。资产故事可以听，但别把故事当钱。

### Check

- Distinguishes assets from liquidity.
- Uses cash-flow lens.
- No investment instruction.

Status: PASS.
