# Public Release Check

Generated by `build_public_skill.py`.

## Included

- Public Skill entry and modules.
- Public research summaries.
- Synthetic/generated cases and evaluations.
- Evidence note without raw excerpts.

## Excluded

- Raw transcripts.
- Long source excerpts.
- Canonical corpus.
- Private source registry/hash/provenance data.
- Political research mode.

## GitHub Publication Checks

- License holder replaced.
- Repository visibility and description selected.
- Public safety scan re-run.
- Repository name uses a generic public-safe package name.
