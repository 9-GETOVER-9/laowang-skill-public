# 大老王 Public-Safe Agent Skill

一个 public-safe 的大老王口播风格 Agent Skill：把公开口播内容蒸馏成人生决策、家庭教育、金融商业、玄学命运与表达风格模块，让 Agent 可以学习其“判断框架”和“口播表达结构”，但不包含原始逐字稿、长段摘录或私有证据包。

本仓库是从私有研究包蒸馏出来的公开版：保留可调用的 Skill 入口、表达风格、领域模块、公开研究摘要和测试案例；不包含原始逐字稿、长段原文摘录、私有 source registry、hash/provenance 包或完整 canonical 语料。

## What Is Included

- `SKILL.md`: Skill 入口和路由。
- `expression_style.md`: 表达风格指南。
- `modules/`: 可调用领域模块。
- `references/research/`: public-safe 研究摘要。
- `cases/`: 可复用公开案例。
- `evaluations/`: 路由矩阵和 smoke/pressure tests。

## What Is Not Included

- 原始音视频、字幕、逐字稿。
- 长段 raw transcript excerpt。
- 可识别私人信息。
- 政治观点复读模式。
- 私有证据包和 source registry。

## Disclaimer

This is an independent research/educational artifact. It is not an official project, endorsement, authorization, or representation of any real person. The Skill imitates distilled rhetorical structure and decision patterns, not identity, private facts, or harmful surface language.
