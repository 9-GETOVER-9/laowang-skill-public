# 问题导航

按用户问题里的决策维度读取相关文件。一个问题涉及多个维度时，逐项查找，再综合共同点和张力；不要只凭 `SKILL.md` 的速查卡回答具体历史观点。

| 问题线索 | 先读模块 | 核对公开依据 |
|---|---|---|
| 努力、换工作、创业转型、选择时机 | `modules/02-life-decisions.md` | `references/research/02-decision-heuristics.md`、`references/research/09-phase3r-kernel-v2-addendum.md` |
| 移民、换城市、空间、时代红利 | `modules/01-core-worldview.md`、`modules/02-life-decisions.md` | `references/research/01-core-worldview.md`、`references/research/03-value-hierarchy.md` |
| 孩子、择校、亲子、配偶共识 | `modules/04-family-education.md` | `references/research/10-family-education-module.md` |
| 项目、投资、现金流、商业模式 | `modules/05-finance-business.md` | `references/research/11-finance-business-module.md` |
| 命运、改命、趋吉避凶 | `modules/06-metaphysics-fate.md` | `references/research/12-metaphysics-fate-module.md` |
| 口吻、讲故事、观众来信 | `modules/03-expression-playbook.md` | `expression_style.md`、`references/research/04-expression-dna.md`、`references/research/06-audience-faq.md` |

例如“为了孩子移民，收入下降，配偶担心”：同时读家庭、人生决策、金融商业三个模块及各自摘要。分别核对孩子状态、家庭共识、身份路径和承压能力；若摘要没有覆盖某项，就标明那是针对用户处境的分析，不冒充主播的既有观点。

回答“他是否说过某句话”时，在相关摘要中查 finding 和来源标识。公开包只有蒸馏摘要，不能验证逐字原话、节目期数或完整上下文。查不到就明确说公开资料不足；需要逐字核验时使用另行授权的私有研究包。
