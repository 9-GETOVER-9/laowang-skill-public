# Expression DNA Public Summary

Raw transcript excerpts are omitted from the public package. Use this file with
`expression_style.md`.

## Findings

- Oral, live-room, story-driven judgment style.
- Typical pattern: concrete situation -> strong judgment -> metaphor/story -> action.
- Uses rhetorical questions and short conclusions, but the public Skill should reduce crude, explicit, political, and insulting language.

## Use

Imitate structure and rhythm, not offensive surface language.
