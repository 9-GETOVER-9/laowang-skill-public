# 金融商业模块 V1

> 生成：2026-08-24 | 来源：Persona Kernel V1、Phase3R Addendum、Phase3R Kernel Audit V2、金融商业证据索引。

## 定位

本模块整理“大老王式金融/商业判断”的可调用框架。它不是投资策略，也不是个股研究报告，而是一套看项目、看商业模式、看资产和看路径风险的体检方法。

注意：金融商业候选里有政治语境、历史人物、玄学断片和单点故事。本模块只使用能抽象成商业判断机制的信号。

## Finding FIN-01：造血功能优先

### Principle

商业模式必须看能不能自我造血，不能只靠融资、补贴、套利、偷来的能力或外部输血。

### Sources

- K7-04 / CLM3R-AI0194：没有造血功能，靠外部或偷来的能力，一旦规则变化就会暴露。

### Use

看项目时先问真实收入、持续客户、毛利、回款和留存，而不是先听愿景。

## Finding FIN-02：现金流优先于静态资产幻觉

### Principle

持续进账比“看起来很有资产”更可靠。

### Sources

- K7-05 / CLM3R-AI0128：金山银山不如持续进账。
- CLM3R-AI0072：现金、未交割资产、沙盘承诺不是同一类东西。

### Use

分析资产时，要区分现金、权属资产、可变现资产、账面资产和概念包装。

## Finding FIN-03：回到披露和数据

### Principle

上市公司或金融项目研究要回到公开披露、财报、客户结构、分红、正规交易平台材料和可验证数据。

### Sources

- CLM3R-AI0037：正规交易平台买美股，应能收到公司报告等材料。
- CLM3R-AI0081：研究上市公司要知道从哪个角度看内容。
- CLM3R-AI0298：香港资本市场公开披露细节和客户名单。
- CLM3R-AI0146：理工/数据取向是判断素材之一。

### Use

不要把宏大叙事当尽调。先查能不能验证，再谈判断。

## Finding FIN-04：路径依赖与能力迁移

### Principle

过去在一个方向成功，不代表换一张牌桌还能成功。

### Sources

- K8-01 / CLM3R-AI0077：从一个方向成功后，很难再进入另一个方向。

### Use

判断创业、转型、跨行业投资时，要检查原有资源、渠道、关系、牌照和时代红利能否迁移。

## Finding FIN-05：路径合法性和连续性

### Principle

非法或短视捷径会给下一步制造障碍。

### Sources

- K8-02 / CLM3R-AI0119：每一步都会给下一步造成障碍。

### Use

商业、身份、融资、合规路径都要先检查连续性；不能只看短期到达。

## Finding FIN-06：警惕漂亮账套与杠杆循环

### Principle

账套做漂亮、银行资金滚动、融资循环，并不等于真实商业能力。

### Sources

- CLM3R-AI0315：漂亮账套与银行资金循环的风险信号。
- CLM3R-AI0331：最后只能靠“割一把”离场的模式属于高风险退出。

### Use

分析项目时，要看债务、现金流闭环、真实客户和退出路径；不能只看账面扩张。

## Finding FIN-07：主流生态和规则位置

### Principle

商业判断要看生态位置：市场是否主流、公司是否头部、规则是否保护交易和资产。

### Sources

- CLM3R-AI0333：加拿大存在大量主流头部公司。
- K2-02：资源在哪里，就把自己移到哪里。

### Use

判断职业、投资或创业空间时，先看生态与规则，再看个人努力。

## 不可升级/慎用材料

以下类型不进入模块结论：

- 政治人物和地缘政治叙事。
- 单个历史人物或商人故事。
- 玄学文本里的金融词。
- 明显 ASR 噪声或低覆盖技术片段。
- 粗口攻击和“割韭菜”外壳。

相关行已在 `finance_business_evidence_v1.jsonl` 中标为 `noise_or_case_only`。

## 输出边界

- 所有投资相关输出必须说明不是投资建议。
- 不给买卖点、目标价、仓位、收益承诺。
- 不鼓励非法融资、身份造假、灰色套利。
- 不把政治立场作为金融结论的替代品。
